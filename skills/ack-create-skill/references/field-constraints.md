# Field Constraints: ack-create-skill

## Required frontmatter
- `name`
- `description`

## Optional frontmatter
- `version`
- `license`
- `compatibility`
- `metadata`
- `allowed-tools`
- `disable-model-invocation` (Claude Code extension; see below)

## Required by this kit
- `metadata.invocation`

## Constraint rules
- `name`: 1-64 chars, lowercase alphanumeric + hyphen, no leading/trailing hyphen, no consecutive hyphens, matches folder name.
- `description`: 1-1024 chars. It is the pointer that decides when the skill is reached (`../../ack-validate-skill/references/writing-for-agents.md`). Model-invoked: state what the skill does, leading word first, then each distinct trigger ("Use when …"). User-invoked: a one-line summary for the person who types the name; a trigger list is optional.
- `compatibility`: optional, 1-500 chars.
- `metadata`: optional map of string keys to string values.
- `metadata.invocation`: `"user"` or `"model"`. Use `"user"` for skills with side effects or a fixed order (create, validate, governance, loop); use `"model"` only when the assistant should start the skill on its own.
- `disable-model-invocation`: `true` if and only if `metadata.invocation` is `"user"`. It is a Claude Code extension outside the Agent Skills spec; claude.ai and the Skills API reject it on upload.
- Codex `agents/openai.yaml` sidecars are generated by the kit installer from `metadata.invocation`; do not author them in the skill folder.
- A user-invoked skill must not be started by another skill; skills may only name the next skill for the user to run.
- `metadata.credits`: required when the skill adapts external material. One string naming the source, its license and copyright, and its URL. Name the origin once in the body too, and add the skill to `THIRD_PARTY_NOTICES.md` (ADR-014).
